# Kaia Cha Portfolio

Static portfolio site for kaiacha.com.

## Public URLs

- `/` - VR intro
- `/Home/` - main portfolio
- `/LifeLine/` - LifeLine case study
- `/anticancer/` - Anticancer case study
- `/koddiz/` - Koddiz case study

## Analytics

Google Analytics 4 is configured in `analytics.js`.

## GitHub Pages

This folder is designed to deploy from the repository root using GitHub Pages.
The `.nojekyll` file is required so GitHub Pages serves `_next` assets.
